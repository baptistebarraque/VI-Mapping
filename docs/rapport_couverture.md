# Rapport de couverture

Produit par `vi couverture` le 25/11/2026. Taux de remplissage de chaque champ, par département d'Île-de-France.

- **%** : part des lignes où le champ est connu. **–** : aucune ligne.
- **\*** : part des lignes concernées. Une absence y veut dire « non », pas « inconnu ».
- Une ligne qui touche plusieurs départements compte une fois dans chacun.
- Les doublons entre sources sont exclus : seule la fiche principale compte.
- Source, adresse web, méthode, date de collecte et confiance : 100 % partout, imposé par le schéma.

## Sources écartées

Leurs conditions d'utilisation, vérifiées avant collecte, interdisent l'extraction automatique.

- **Carte du Réseau AMAP Île-de-France** : Reproduction totale ou partielle prohibée ; transfert d'informations vers un site tiers interdit.
- **FCPE Paris, conseils locaux** : Toute reproduction, même partielle, interdite sans accord exprès par écrit.
- **monenfant.fr (accueils périscolaires)** : Les conditions limitent l'usage à des fins personnelles et non commerciales, interdisent toute exploitation commerciale et annoncent des poursuites pénales pour toute autre utilisation que la mise en relation des familles avec les structures d'accueil.
- **PEEP, associations locales** : Reproduction autorisée pour un usage personnel et privé uniquement ; toute autre utilisation expressément interdite. Aucun site départemental francilien joignable.
